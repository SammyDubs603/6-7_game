# 6-7 World

A bright, family-friendly multiplayer party-game concept turned into an interactive web prototype.

## Features in this prototype

- **6-7 Trigger System**: tap the main button (or use voice, when supported) to cause random world reactions.
- **Combo Gameplay**: chain taps/gestures to build combo multipliers and unlock rewards.
- **Party Modes**: switch among Co-op Quest, Rhythm Battle, 6-7 Tag, and Charades.
- **Social Play Mock**: local player counter and team score race simulation.
- **Viral Hooks Mock**: generate a “6-7 reaction clip” after building enough combo energy.

## Run locally

```bash
python3 -m http.server 4173
# then open http://localhost:4173
```

> Voice recognition depends on browser support for Web Speech API.
